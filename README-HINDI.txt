HOW TO EDIT PRODUCTS
1. Open products.js in a text editor.
2. Each product has: id, name, category, tag, description, image.
3. Duplicate a product object and change its fields to add more products.
4. Use a direct image URL for image. For best results, use your own uploaded product image URL.
5. Keep every product id unique.

HOW TO PUBLISH FREE USING GITHUB PAGES (MOBILE)
1. Sign in at https://github.com/
2. Create a new PUBLIC repository named: rcf-furniture
3. Upload ALL FOUR website files (index.html, style.css, products.js, script.js) to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. Your free address will look like:
   https://YOUR-USERNAME.github.io/rcf-furniture/

CUSTOM DOMAIN
You can buy a domain separately later, then connect it in Settings -> Pages -> Custom domain.
GitHub Pages hosting can remain free. Do not buy hosting just to publish this static catalogue.

LIMITATIONS
- This is a product catalogue and WhatsApp enquiry cart, not an online payment/checkout system.
- Cart is stored in the visitor's browser.
- There is no stock/admin dashboard or online order database.
- Product images need internet access.
